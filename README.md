# Professional Low-Code Performance Scanner

Automated performance testing system focused on low-code web applications (e.g., Bubble.io, OutSystems, Airtable).

## Measurement Accuracy

This scanner uses real browser performance APIs:
- **Chrome DevTools Protocol** for memory/network
- **PerformanceObserver** for Core Web Vitals
- **Navigation Timing API** for load metrics
- **NO** synthetic or estimated data

## Key Features

- **Platform-Aware Scanning**: Automatically detects low-code platforms and applies tailored analysis.
- **Multi-Scenario Testing**: Test homepage load, regular use, heavy list loads, and more.
- **Deep Telemetry**: Capture Core Web Vitals, memory peaks, and network traces.
- **Enterprise Reporting**: Generate professional reports in HTML, PDF, JSON, and Excel formats.
